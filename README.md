# 人工智能工作图谱外部功能演示

本分支仅用于向外部开发单位展示页面结构、导航关系、筛选交互、图表和数据字段。

## 数据说明

- 所有业务数据均为合成示例，不代表真实单位、项目、政策、专家或统计结果。
- 每个业务页面使用少量多类型合成记录，覆盖筛选、搜索、排序、详情和状态测试。
- 真实附件、真实地图信息、内部部署配置和遗留内嵌数据均已从本分支移除。

## 本地预览

```bash
python3 -m http.server 8080
```

访问 `http://localhost:8080/index.html`。

## 数据维护

以 `data/*.json` 为真源，修改后运行：

```bash
python3 data/sync.py
```

该命令会同步生成用于 `file://` 预览的对应 `.js` 文件。
